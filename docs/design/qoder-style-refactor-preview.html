Bookmark Desk · Qoder 风格重构稿

Token 与组件规格直接取自 qoder.cn 线上计算样式，用于确认视觉方向与组件拆分方案。确认后按本稿改造源码。

01 / Principles

从 qoder.cn 提炼的六条设计哲学

这是本次重构的判断依据：任何一处样式争议，回到这六条上裁决。

  1. 01
    边框承重，不用阴影线上卡片 box-shadow 全部为 none，层级完全由 1px 实线边框与底色差表达。重构后取消所有投影，玻璃拟态与模糊一并移除。
  2. 02
    暖调中性色打底，品牌绿只在关键动作出现墨色 #0f0d0c、布局底 #f2f4f2、边框 #e6e6e6；绿色只出现在主按钮 #255a41 与状态点缀 #80c776，不做渐变背景。
  3. 03
    层级靠字号与留白，不靠字重标题字重 500 而非 700，正文 13px、标签 11px 等宽大写。信息密度靠间距节奏撑开。
  4. 04
    虚线 hairline 是标志性图形语言qoder.cn 用 repeating-linear-gradient 的 5px 虚线做模块分隔与网格描边。重构后用于 Tab 轨道、模块头分隔、弹窗脚注。
  5. 05
    等宽字体承担"技术元信息"域名、计数、百分比、状态行统一用 Menlo，与正文形成可读的语义分层。
  6. 06
    动效只服务反馈统一 120–200ms / cubic-bezier(0.4,0,0.2,1)，只过渡 color、background、border。取消 GSAP 入场时间轴与位移缩放。

06 / Architecture

组件拆分方案

App.vue 现在 2106 行、BookmarkGroup.vue 691 行，模板、书签 CRUD、拖拽、动效、背景设置混在一起。按"容器 / 展示 / 组合式逻辑"三层拆开，行为不变。

目标结构

src/
├─ App.vue                      容器：装配 + 布局
├─ composables/
│  ├─ useBookmarkTree.js       chrome.bookmarks / 回退数据
│  ├─ useBookmarkActions.js    重命名 · 删除 · 打开
│  ├─ useBookmarkDrag.js       拖拽与放置目标
│  ├─ useBackgroundImage.js    背景设置读写
│  ├─ useTheme.js             浅色 / 深色持久化
│  └─ useContextMenu.js        右键菜单位置与关闭
├─ components/
│  ├─ AppTopbar.vue            品牌 + 动作按钮
│  ├─ FolderTabs.vue          Tab 轨道 + 放置提示
│  ├─ BookmarkBoard.vue       模块网格 + 空态
│  ├─ BookmarkModule.vue      单个目录卡片
│  ├─ BookmarkRow.vue         单条书签 / 子目录行
│  ├─ BookmarkTree.vue        递归 + 拖拽容器

07 / Rollout

确认后的实施顺序

Step 1

令牌与基座

重写 tokens.css，双主题一次到位，跑通现有页面。

Step 2

组件拆分

先抽 composable，再切组件，保持每步可运行。

Step 3

动效收敛

删除 GSAP 时间轴，改 CSS 过渡并移除依赖。

Step 4

验证

npm test、build、浏览器截图逐屏对照本稿。

需要你确认的三处取舍：① Tab 激活态用深色胶囊（也可改为下划线式）；② 书签行左侧 18px 字母缩写占位（Chrome 提供 favicon 后可换成真实图标）；③ 深色主题的具体色值由浅色同源推导，线上 qoder.cn 未公开深色令牌。
