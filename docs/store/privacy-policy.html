Bookmark Desk 隐私政策

生效日期：2026-10-24　最后更新：2026-10-27

Bookmark Desk 不收集、不上传、不共享你的书签、设置或上传的背景媒体。 书签与设置全部留在本机，扩展没有任何自有服务器。页面会请求字体服务和公开预设壁纸 目录，但不会把书签内容或设置发送给这些服务。

1. 我们收集哪些信息

没有任何收集。本扩展不集成统计、埋点、广告或崩溃上报 SDK，也不创建用户标识。 本扩展不会读取或上传书签之外的浏览历史、页面内容、账号信息或表单数据。

2. 扩展申请的权限与用途

权限用途
bookmarks 读取本机 Chrome 书签树，用于在新标签页按目录渲染卡片。仅在你主动重命名、删除或拖拽整理时写回书签数据。
favicon 读取 Chrome 本机已缓存的网站图标，用于显示书签卡片上的站点图标。图标取自本地缓存，不会向第三方图标服务器请求。
新标签页替换 通过 chrome_url_overrides 用本扩展页面替代默认新标签页，这是扩展的核心功能。

3. 数据存放在哪里

  • 书签数据：在浏览器内存中读取用于渲染。只有你点击「导出备份」时，才会把书签、显示设置、本地背景和目录密码哈希下载成一个保存在你电脑上的 HTML 文件。扩展不上传这个文件。
  • 界面设置（卡片尺寸、主题、背景参数等）：存放在本机浏览器的 localStorage。
  • 选中的预设壁纸：只保存其公开 http/https 地址；媒体文件仍由公开 CDN 提供，不下载进扩展私有存储。
  • 上传的背景图片或 MP4 视频：存放在本机浏览器的 IndexedDB。

扩展不会把以上数据发送到任何服务器。你主动导出的备份文件由你自己保存。卸载扩展或清除扩展数据即可删除仍留在浏览器里的副本。

4. 网络请求

核心书签读取、整理和设置功能在扩展包内运行，不依赖网络。本扩展会产生以下资源请求：

  • 页面默认从 fonts.googleapis.com 和 fonts.gstatic.com 加载可选字体的 CSS 和字体文件。
  • 选择 MiSans 或鸿蒙字体时，会按需从 cdn.jsdelivr.net 加载对应字体 CSS 和字体文件。
  • 打开显示设置时，会从 api.github.com 读取公开仓库 refanbanzhang/cdn-images 的 wallpapers 目录文件名；目录接口不可用时，回退到 raw.githubusercontent.com 上的 wallpapers/index.json。选中某张预设后，页面从 cdn.jsdelivr.net 加载对应的图片。
  • 这些请求只包含浏览器发送的常规网络请求信息，不包含用户书签、书签地址或本扩展的设置。
  • 上传的背景图片和 MP4 视频只保存在本机 IndexedDB，不会上传。预设图库加载失败时，仍可继续使用本地上传。
  • 当你主动点击书签时，浏览器会打开你选择的目标网站；这属于书签本身的导航行为。

网络不可用时，字体会回退到系统字体，预设图库显示失败提示，不影响书签的基本读取和整理。

5. 第三方共享

本扩展不出售、不转让、不向第三方披露用户书签、设置或背景媒体。 字体服务商可能收到加载字体资源所需的常规请求信息，但本扩展不会向其发送用户书签或设置。

6. 远程代码

本扩展不加载远程 JavaScript，也不依赖远程代码执行。字体 CSS 和字体文件属于外部资源， 仅用于字体显示；所有业务脚本都随扩展包一同分发。

7. 儿童隐私

本扩展不面向 13 岁以下儿童，也不收集任何年龄相关信息。

8. 政策变更

若本政策发生变更，本页顶部的「最后更新」日期会同步修改，重大变更会在扩展的商品详情页说明。
