# Chrome 应用商店提审材料

直接复制粘贴用。`[方括号]` 是需要你替换的内容。

## 一、账号（一次性）

- 地址：`chrome.google.com/webstore/devconsole`
- 费用：一次性 **$5** 注册费（唯一强制花费）
- 前置：Google 账号开启两步验证；否则无法发布
- 需完成身份验证
- 因欧盟 DSA 需声明 **trader / non-trader**：纯个人业余发布选 non-trader（商店不展示联系方式）；有商业主体选 trader

## 二、打包

```bash
npm run release    # = vite build + 打包成 release/bookmark-<version>.zip
npm run zip        # 只打包现有 dist/，不重新构建
```

产物规格已核对：`manifest.json` 在压缩包根目录、无外层文件夹、无 `.DS_Store`、约 66 KB。

**版本号铁律**：首次上传后拿到 extension ID，之后每次更新 `version` 必须严格大于商店已发布版本，否则上传直接被拒。版本号写在 `public/manifest.json` 与 `package.json` 两处，必须保持一致。

## 三、商品详情

### 简短说明（官网摘要，上限 132 字符）

```
把 Chrome 书签按目录铺成新标签页：一格一卡，拖拽整理，一键打开常用站点。
```

### 详细说明

```
书签启动页把 Chrome 的新标签页换成你自己的书签台：不再显示空白页或导航站，
打开新标签即见常用站点。

主要功能
· 按目录展示：书签树里的每个文件夹就是一张卡片，卡片内可直接打开其中的书签与子目录
· 一格一卡：顶层目录卡与散落书签卡同宽同高，排布整齐；卡片尺寸提供四档档位可调
· 目录 Tab：文件夹在顶部成 Tab，可拖动换位；把书签拖到 Tab 或目录卡上即可移入
· 拖动整理：拖书签调顺序、拖目录换位、拖到文件夹即移入，调整立刻同步回 Chrome 书签
· 右键菜单：直接重命名或删除书签与文件夹（删除文件夹有二次确认）
· 背景与主题：可上传本地图片作背景，显示强度与磨砂可调；浅色/深色跟随系统
· 字体可选：系统 / Inter / Geist / Plex / Manrope 五档，选择会持久化
· 图标本地取：网站图标读 Chrome 本地缓存，不向第三方发起请求

不联网、不收集数据、无远程代码：全部逻辑打包在扩展内，书签与设置只存本机。
```

### 英文（可选，填了会给非中文语言环境展示）

Summary: Turn Chrome's new tab into a tidy grid of your bookmarks, organized by folder.
```

## 四、隐私权规范（逐项照填）

### 单一目的说明

```
在新标签页按目录层级展示用户本地的 Chrome 书签，并允许用户对书签与文件夹做重命名、
删除和拖动整理。
```

### 权限理由

| 权限 | 理由（直接粘贴） |
|---|---|
| `bookmarks` | 读取用户的书签树，用于在新标签页渲染目录卡片与书签卡片；仅在用户主动重命名、删除或拖动整理时写回书签数据。不读取、不上传任何其他浏览数据。 |
| `favicon` | 读取 Chrome 本地已缓存的网站图标，用于展示书签卡片上的站点图标。图标取自本机缓存，不会向任何第三方服务器发起请求。 |

### 数据使用

| 问题 | 选择 |
|---|---|
| 是否收集用户数据 | 否（不上传、不共享、不出售） |
| 书签数据 | 仅在本机内存中读取用于渲染，不落盘、不外传 |
| 设置与背景图 | 存本机（设置存 localStorage，背景图存 IndexedDB） |
| 网络请求 | 无。背景图只支持上传本地图片，不存在需要联网取图的入口 |
| 是否使用远程代码 | 否，全部逻辑打包在扩展内 |
| 隐私政策 URL | `[你的隐私政策页地址]`（模板见同目录 privacy-policy.html） |

## 六、提交

1. 控制台上传 zip，Chrome 自动读取 manifest 抓权限
2. 填完「商品详情」+「隐私权规范」才允许提交
3. **先选「仅限测试人员」发布**，用一个干净 Chrome 用户走一遍完整安装流程，确认无异常后再转公开
4. 首次提交不要勾「自动发布」，先人工看审查意见再放行
5. 审核通常 1-3 天，也可能到数周
6. 名称里不要出现 `Chrome`、`Google` 等商标词

## 七、后续更新循环

#    public/manifest.json -> version

# 2. 控制台上传 release/bookmark-<version>.zip -> 提交审核
```
